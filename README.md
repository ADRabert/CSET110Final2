# CSET 110 Final 2: Login Page

## Final Info
This second part of the CSET 110 final project involves creating a login page template using information learned from previous lectures. Since this class is focused more on web design than functionality, the visuals of the login page must look appealing.

## Requirements
- Custom login & signup page (either combined or separate)
- Cohesive design with a particular product/service theme
- Ability to tell what product/service user is logging in to or signing up for
- Animated effects (optional)
